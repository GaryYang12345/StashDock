# StashDock 1.0.1

Install StashDock Companion directly from the [Chrome Web Store](https://chromewebstore.google.com/detail/bbglcpbhnobjhgccjinejnnlcefelkee).

Windows Desktop and the ChatGPT plugin now open the store from Settings and include updated setup instructions in English and Chinese.

## Downloads

| File | System |
| --- | --- |
| `StashDock_1.0.1_x64-setup.exe` | Windows 10 or 11, x64 |
| `stashdock-plugin-1.0.1-win32-x64.zip` | ChatGPT plugin for Windows x64 |
| `stashdock-extension-chrome-1.0.0.zip` | Optional manual installation; the Chrome Web Store is recommended |

Mac downloads remain available in [1.0.0](https://github.com/StashDock/StashDock/releases/tag/v1.0.0).

Windows may show a SmartScreen prompt on first launch. See the [installation guide](https://stashdock.app/guide) for setup and usage.

`SHA256SUMS.txt` contains the download checksums.
