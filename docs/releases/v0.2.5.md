# StashDock v0.2.5 — first Windows release

One local library, independent Desktop and ChatGPT entry points, reusable AI context.

## Downloads

- **Windows Desktop 0.2.5:** `StashDock_0.2.5_x64-setup.exe`.
- **ChatGPT local plugin 0.4.27:** `stashdock-plugin-0.4.27-win32-x64.zip`.
  Includes pinned Node and native helpers; extract the complete archive before
  registering its local marketplace. No separate Desktop/Node/npm needed.
- **Browser extensions 0.4.13:** Chrome, Edge and Firefox ZIPs. Chrome/Edge use
  Load unpacked; Firefox is a temporary development installation until signed.
- **Mac developer handoff:** `StashDock-Mac-Handoff-v0.2.5.zip` contains the prompt,
  rules, Arc Skill and exact baseline; source is cloned from this repository.
- `SHA256SUMS.txt` and `release.json` record integrity and the source commit.

## Included

Visual references, tags and search; original-file Open/copy/drag; editable context
with Markdown preview; current-page browser capture; independent AI panel with
search/recommendation, explicit note/link saves and approved tag organization.
Desktop includes an optional 144px floating folder and normal-window mode.
English/简体中文 and system/light/dark appearance are supported.

Public screenshots use system Evergreen WebView2 rather than a bundled browser.
The plugin ships its own verified Node runtime. Source, shared behavior, native
adapters and development rules live in this repository, not separate app copies.

## Install and limits

Read [Windows installation](../INSTALL_WINDOWS.md) and
[ChatGPT plugin installation](../windows-plugin-install.md).
Use the complete plugin ZIP, **not** the automatic Source code ZIP or an unbuilt
Git checkout. This is a local plugin for compatible desktop hosts, not a web
ChatGPT store listing. Host capabilities govern composer file attachment.

Windows x64 only. The installer is unsigned and may show an unknown-publisher
warning; do not disable platform protections. Store approval, clean-machine
installation and macOS signing/notarization are not claimed. macOS, Claude and
Safari are not released. No cross-machine data sync is provided.
