## Layout

- `src/` shared React UI (Desktop WebView, ChatGPT MCP App, browser workbench)
- `src-tauri/` Windows desktop (Tauri 2, Rust, SQLite) and native helpers
  (`stashdock-preview` renderer, `stashdock-storage` dialogs/relocation)
- `plugins/stashdock/server/` MCP server (Node `node:sqlite`) over the same library
- `extension/` Chrome/Edge/Firefox Save-page sidebar

Desktop (Rust) and the MCP server (Node) are two implementations over one
SQLite library. Shared behaviour must keep one contract: shared SQL files
(`schema.sql`, `search-index.sql`), mirrored modules with matching tests
(`originals.rs` / `original-files.mjs`, `chosen_files.rs` / `chosen-files.mjs`,
`search.rs` / `reference-search.mjs`) and JSON fixtures checked by both.

## Checks

```bash
npx tsc -b                      # type check
node --test tests/*.test.mjs    # frontend + MCP server (Node 24)
cd src-tauri && cargo test      # native (Windows-only modules need Windows)
```

On Windows also run `npm run desktop:test`; WebView2 rendering, OLE drag/clipboard
and window lifecycle can only be verified there. Prefer behaviour tests over
source-text regex assertions.

## Commits

Commit on a branch or locally on `main` when asked; never push without the user.
Do not commit generated runtimes, personal libraries or `output/` evidence.
`plugins/stashdock/dist` and `web/shelf.html` are generated by `npm run plugin:build`.
