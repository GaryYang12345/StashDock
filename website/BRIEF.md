# StashDock 官网：定位与设计方向

## 一句话

**StashDock 是你的个人 AI 上下文库（personal context library）。** 把散落在各个平台、各种形式的
收藏（网页、帖子、文件、笔记、prompt、规则）放进一个看得见的库里，需要时一步交给任何 AI。

英文主标语：**Your context, one move away.**

## 本质

AI 越来越强，但每次对话都从零开始。真正决定结果的，是你交给它的上下文：项目背景、参考资料、
写作规则、常用 prompt、之前的结论。这些东西：

- **反复要用**：同一套规则、背景、示例，在不同对话、不同 AI 里一遍遍粘贴。
- **散落各处**：浏览器书签、X/小红书收藏、下载文件夹、笔记软件、聊天记录里。
- **找的时候最难**：知道"有这么一份"，但不知道放在哪，找的时间比用的时间还长。

StashDock 把"收集 → 找到 → 交给 AI → 把有价值的结果存回来 → 下次再用"做成一个闭环。
它不是又一个收藏夹，也不是又一个 AI 聊天应用；它是你和所有 AI 之间的那一层上下文。

## 四个优势（网站的主干）

1. **哪里都能收进来**：浏览器扩展一键保存正在看的网页/帖子；导入书签、链接、文件、笔记；
   甚至让 AI 在对话里把值得复用的规则、prompt 存进来。
2. **一眼就能找到**：所有收藏以卡片可视化呈现；标签就是你的上下文分组；搜索即时；
   桌面悬浮文件夹随叫随到，悬停即可快速搜索。
3. **一步交给任何 AI**：插件里一键 Add to chat；桌面端一键复制或直接拖进任何 AI 聊天窗口，
   原文件和上下文一起带过去。
4. **让 Agent 帮你**：接入 MCP 和 Skill，AI 能帮你找、帮你整理标签、帮你创建收藏。
   在一个窗口存下的规则，可以给另一个窗口、甚至另一个 AI 用。

贯穿始终的底层承诺：**你的库在你自己的电脑上**。桌面端、插件、浏览器扩展共用同一个本地库。

## 设计方向

- **气质**：苹果式的优雅、高级、克制。大量留白，浅色中性表面，黑白品牌，靠字号、间距和对比
  建立层级。不用渐变、发光、装饰性大写眉题和模板化的三栏图标卡片。
- **品牌形象**：悬浮文件夹是唯一的拟物主角（与产品同一份插画与投影）。网站里它可以被拖动、
  悬停后浮出搜索框，和桌面端的手感一致。
- **字体**：标题用品牌字体 Srotone（Semi Bold，字距 -4%，行高 Auto）；正文和界面用 Inter；
  中文回落到苹方 / 微软雅黑，中文不加负字距。
- **可交互，而不是截图**：网页里的卡片、Add to chat、复制、拖进输入框、浏览器保存、Agent 存规则，
  都用产品同一套组件和反馈（黑 → 绿 → 黑），用户在网页上就能摸到产品的手感。
- **AI 平台 logo 流**：桌面端能复制/拖进任何 AI 应用，所以展示主流 AI（国内外）；插件目前支持
  ChatGPT（Codex），Claude 即将推出。

## 页面结构

1. 首屏：标语 + 可拖动、可悬停搜索的悬浮文件夹 + 下载
2. 问题：上下文散落各处（散落的卡片随滚动收进文件夹）
3. 现场试用：左边收藏库，右边一个 AI 对话框；Add to chat、拖进输入框、按标签筛选
4. 四个优势：收进来 / 找得到 / 交出去 / 让 Agent 帮你（各带一个小交互）
5. 支持的 AI：logo 流
6. 本地与个人化：一个库，三个入口
7. 下载：Windows 桌面端、ChatGPT 插件、浏览器扩展；macOS 即将推出
